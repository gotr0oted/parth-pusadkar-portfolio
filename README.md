# Parth Pusadkar — Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript. It showcases my education, skills, projects, internship experience, patent publication, certificates, and contact links.

## Built with

- HTML5
- CSS3
- JavaScript

This is a static website. It does not need a package manager or build step.

## View locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

An internet connection is needed for Google Fonts and project photos loaded from Unsplash. The portfolio’s other files are included in the repository.

## Portfolio sections

- About me and education
- Skills and academic results
- Projects
- Business Analytics internship at Maincrafts Technology
- Published patent application
- Certificates and résumé
- Contact details, LinkedIn, and GitHub
