# Parth Pusadkar — Portfolio

A personal portfolio website introducing my education, skills, projects, internship experience, patent publication, certificates, and contact links.

## Built with

- HTML5
- CSS3
- JavaScript

The site is a static webpage and does not require a package manager, build step, or server framework.

## View it locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

An internet connection is needed for the Google Fonts and project photos loaded from Unsplash. The rest of the page and its local documents are included in this repository.

## Portfolio sections

- About me and education
- Skills and academic results
- Projects
- Business Analytics internship at Maincrafts Technology
- Published patent application
- Certificates and résumé
- Contact, LinkedIn, and GitHub links
